# 拍手 / 手机音频模式

波形区上方145～221,181～202位置是模式按钮：CLAP拍手，PHONE手机音频。单次按下切换，持续按住不反复切换。默认CLAP，两板固件相同；任意一板切换后通过既有CRC控制报文同步，SLAVE请求重复发送直到MASTER确认。温度配置保持。切换清除旧捕获、配对、重发结果和上一次时差比较参考，第一次新模式测量的时差变化量为---。

CLAP保留原拍手分支：短促形状检查、主起音附近包络对齐、6倍背景噪声门限、4倍用户原始幅值的结果峰值门槛。

PHONE单独采用4倍背景噪声门限、1倍用户原始幅值的结果峰值门槛，取消拍手形状启发式对手机测试音的拦截；使用普通音频的波形相关和周期性音频包络消歧。250Hz～8kHz滤波、已有相关质量和时间范围检查保留。适用于有明确起音的标准脉冲/扫频测试音，不保证连续音乐或持续纯音都可测距。

模式控制共用UDP50003设置消息，版本2，字节26为模式；其余温度字段保持。测量协议版本6：波形字节27高位为模式、低位为短促标志；结果字节7高位为模式、低位为声源是否在MASTER。接收拒绝模式不一致的旧波形或旧结果。此次两板同时升级。

测试：IAR0错误0警告；tools/test_temperature.py 的实际双节点C模块测试新增MASTER切换和SLAVE切换（含3个包丢失后重试）、确认温度设置不受影响；滤波/短促分类和时差变化量测试仍通过。实板触屏同步和手机测试音触发、精度、换设备、抗误触发仍待现场验证，不能宣称手机问题已全部解决。手动选择模式不是完整的自动拍手/音频分类验收。
