# 声音到达时刻与时差变化量显示

当前固件按用户最终要求显示：J_n = abs(abs(dt_n) - abs(dt_(n-1)))。

dt 为同一次声音在两板之间经相关对齐、实际用于测距的带符号传播时差；n与n−1为主板连续两次成功配对的测量。拒绝的声音、结果重传均不更新上一次时差。

距离面板标题旁显示 |dDT| xxx.x us，单位微秒，保留0.1微秒。先在纳秒整数中取两次绝对时差之差的绝对值，最后显示时四舍五入；不是本板相邻发声间隔，不是同一次声音的绝对传播时差，也不是时钟同步误差。

例如上一次dt=−800.0us、本次dt=+805.5us，则显示5.5us，不是1605.5us。首次成功结果或断网/失锁恢复后的首次结果缺少参考，显示---；第二次成功结果开始显示。静默期间若结果已超时，时间差显示也随结果失效。

主板计算后通过同一测量结果包发送到从板，避免从板丢过某个结果而自行选取不同的上一次事件。两板显示一致。

底部状态栏保留 TOA#事件编号 秒.微秒s，是本板最近一次独立起音检测的同步时基时间戳；可在测距未成功时更新，与面板的成功配对指标不同。

测距协议版本5：波形1056字节，ACK32字节；结果36字节，23～26为声速mm/s，27～30为时差绝对值变化量ns，31为是否已有上次参考，32～35为CRC32。两板需同时升级。

IAR编译0错误0警告，两板已下载。tools/test_arrival_difference_change.py 调用当前生产计算段，验证首次占位、先绝对后作差、零变化、纳秒计算及失锁后重置。显示分辨率不代表已经通过±100us重复性验收。

## 73cm现场核对

用户确认麦克风间距现为约730mm（不再是此前280mm）。读取时两板运行PHONE模式；稳定传播时差约2.11ms与该间距相符。历史中713mm/2057220ns到1090mm/3145571ns的相邻结果，变化量为1088.351us，说明大显示值可以由测距跳变直接产生；不应视为固定位置重复性正常。生产计算段测试仍通过，未发现该公式或ns→us单位换算错误。此快照不能作为CLAP模式性能结论。

已仅切换运行设置至CLAP，未修改PHONE算法、未修改显示公式、未截断大显示值；从板确认audio_mode/audio_capture_mode/measurement_audio_mode均0、pending0、同步锁定。模式切换会清空上一次时差参考，因此第一次新模式结果显示---。73cm CLAP实际重复性仍待固定声源拍手复测。
