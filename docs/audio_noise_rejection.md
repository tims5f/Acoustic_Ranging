# 音频滤波与防误触发进展（2026-11-04）

## 当前固件

- 48kHz 双通道连续处理，250Hz 二阶 Butterworth 高通串联 8kHz 二阶 Butterworth 低通；两板各通道使用相同固定系数与独立连续滤波状态，滤波后的 PCM 同时进入触发、缓存和相关计算。
- 使用幅值背景估计：向上慢适应、向下较快适应，对大瞬态限制其对背景估计的贡献；门限 max(用户原始门限/2, 背景幅值×6+16, 48)，释放门限为触发门限75%，启动学习1秒。
- 测距事件峰值要求达到用户阈值对应原始幅值的4倍。初次试验曾暂时降低到1倍，静默出现弱瞬态误报后恢复4倍。触发门槛与结果质量门槛含义不同；之前固定提高触发门槛到2倍原始幅值已撤回。降低用户门限也会降低结果峰值门槛。
- 依据触发后前8ms能量占比大于70%、峰值平方超过全捕获后段平均能量8倍，识别短促事件候选。两板候选类型一致才允许配对；双方均为短促事件时使用 RMS 包络导数相关，继续使用相关度、峰歧义和传播时差边界检查。普通音频维持波形相关与包络消歧。
- 报文type1字节27携带短促候选标志；此次两板已一起升级。该启发式标志不等于已经完成标准音频/拍手分类验收，敲击等其他共同瞬态仍可能通过。
